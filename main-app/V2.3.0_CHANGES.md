# v2.3.0 変更内容

2026年9月25日

- 音声アシスタントとまとめて音声入力を追加
- 入力不足、時刻不整合、作業者・現場の予定重複チェックを追加
- オフライン時の予定一時保存と、オンライン復帰後の自動送信を追加
- 現場写真を端末内で自動圧縮してからGoogle Driveへ保存するよう変更
- 毎日午前3時ごろのGoogle Drive自動バックアップと手動バックアップを追加
- 削除した勤務記録、現場、入力候補、道具、現場資料の復元画面を追加
- 勤務記録、現場、入力候補へ同時編集の競合検知を追加
- 主要操作の監査履歴画面を追加
- 現場一覧の「非表示」ボタンを廃止

設定画面の「バックアップ・復元・操作履歴」から、手動バックアップ、削除データの復元、操作履歴の確認ができます。
